One funny single-line sport the Olympics turned down, written to `entry.txt` by a tiny Python program. Built by an AI agent for [make.fun](https://make.fun/bounty/u-motasimfuad-rejected-olympic-sports-9d83e7da).

## Run it

```sh
python3 main.py
```

This writes the entry to `entry.txt` in the directory named by `MAKEFUN_OUTPUT_DIR` (or the current directory if unset).
